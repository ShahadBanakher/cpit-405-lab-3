HTML is the standard language used to create web pages. It provides the structure and content of a webpage.

HTML uses different elements such as headings, paragraphs, links, images, lists, tables, and forms.

HTML is used to create the structure of a webpage. Water can be written as H2O, and 102 equals 100. This text is inside a span.

Web development combines HTML, CSS, and JavaScript. The formula x2 can contain a superscript, while CO2 contains a subscript. This is another span element.

Headings organize a webpage into different sections. E = mc2 is a famous equation, while H2O is the formula for water. Span can be used to style small parts of text.

Links allow users to navigate between different webpages. The number 52 is 25, and O2 represents oxygen. This is a span inside the paragraph.

Tables and forms are useful HTML elements for organizing information and user input. x3 represents x cubed, while H2 represents part of a water molecule. This is the final span element.
